# chethanbhatbs.github.io

My portfolio site - **apps, tools, and Claude Code skills with one-click install**.

🔗 **Live:** https://chethanbhatbs.github.io

## What's here
A single self-contained `index.html` (no build step) served via GitHub Pages, titled *"Chethan Bhat - Projects & Tools"*, with three sections:
- **Apps & Tools** - full-stack apps and utilities (e.g. JSON diff, Chrome extension, CMS).
- **Claude Code Skills** - my published skills, each with a one-line install command.
- **Learning** - long-form books/guides I've written.

## Editing
Edit `index.html` and push to `main`; GitHub Pages redeploys automatically. `LICENSE` covers the repo.
